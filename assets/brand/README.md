# Sanket brand assets

Place the three supplied files here before starting the build:

| File | What it is |
|---|---|
| `sanket-mark.png` | Standalone mark — two ribbons, sphere, hand |
| `sanket-wordmark-latin.png` | "SANKET" with the mark as the S |
| `sanket-lockup-devanagari.png` | संकेत + tagline समझ से समाधान तक |

See section 6.4 of `SANKET-BRIEF.md` for how these may and may not be used.

Short version: take the **structure** and the **two anchor hues**. Do not carry the
multi-stop gradients into UI surfaces.
