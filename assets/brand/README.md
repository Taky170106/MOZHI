# Mozhi brand assets

Place the three supplied files here before starting the build:

| File | What it is |
|---|---|
| `mozhi-mark.png` | Standalone mark — two ribbons, sphere, hand |
| `mozhi-wordmark-latin.png` | "MOZHI" with the mark as the M |
| `mozhi-lockup-tamil.png` | மொழி + tagline மொழி வழி தீர்வு |

See section 6.4 of `MOZHI-BRIEF.md` for how these may and may not be used.

Short version: take the **structure** and the **two anchor hues**. Do not carry the
multi-stop gradients into UI surfaces.
